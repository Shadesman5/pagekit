- **⚠️ Architect decisions + verified discovery (Refactorer MUST heed):**
  1. **How URLs resolve today (verified):** `$view->script()/style()` and `UrlProvider::getStatic()` → `Locator::get()` (prefix table + bare-root fallback, each entry `file_exists`-checked; `add()` prepends, so most-recently-added path wins; multi-path prefixes are a first-class feature) → `Filesystem::getUrl()` → `FileAdapter` registered on the `request` event with `filesystem.path` (= app root) + request base URL, mapping `<approot>/X → <baseUrl>/X`. This single mapping is why everything under the repo root is a URL today.
  2. **`public/` mirrors the served namespace** (per task prompt: existing per-module bundle names and theme CSS paths, just relocated): `public/app/**`, `public/packages/**` — all build-produced/published, **gitignored**; committed in git are only `public/index.php` and `public/.htaccess` (`/public/*` ignore + `!` exceptions; note the existing `**/app/bundle/**/*.js` ignore already matches the relocated bundles). `public/storage` is a symlink to `../storage` (whole tree — see decision 6).
  3. **Servable categories (all must land in/via `public/`; none stay behind):**
     (a) Vite bundles `<module>/app/bundle/*.js` (56 entries, 17 groups — `scripts/bundle-entries.mjs`); outDir gains a `public/` prefix, `entry.output` semantics unchanged.
     (b) Vendor asset copies (`scripts/assets.mjs` dests): `app/assets/{uikit,vue,flatpickr,lodash}` and `app/system/modules/editor/app/assets/{tinymce,marked,codemirror}` → same paths under `public/`.
     (c) LESS outputs (`scripts/styles.mjs`): `app/installer/**/css/*.css`, `app/system/modules/theme/**/css/*.css`, `packages/pagekit/theme-one/css/theme.css` → same paths under `public/`. **theme-one's compiled `css/theme.css` is a tracked file today — it becomes build-output-only under `public/` (untrack the committed copy; keep sources).** Decide via `git log`/usage whether the tracked copy must remain for packaging parity — default: untrack, the pipeline regenerates it.
     (d) **Committed static assets referenced at runtime (discovered — easy to miss):** `app/system/assets/**` (pagekit logos, `js/uikit-icons(.min).js`), `app/system/modules/theme/{favicon.ico,apple_touch_icon.png}`, editor `tinymce_skin` (committed beside the copies), `app/modules/debug/assets/**`, module menu icons (`installer:assets/images/icon-marketplace.svg`, …), blog `assets/css/blog.admin.css`, theme-one images, package-root icon files (`extra.image` in package `composer.json`, e.g. blog `logo.svg`), finder's non-bundle runtime script `app/storage.js`. Publication rule: per module/package tree copy the conventional servable dirs (`app/bundle/`, `app/assets/`, `assets/`, `css/`, `js/`, `images/`, `fonts/`) + module/package-root `*.ico|*.png|*.svg|*.jpg` + `app/**/*.{js,css}` (covers `app/storage.js`-style direct registrations; over-inclusion of a few unbundled source `.js` is accepted — they are public today anyway and contain no secrets). Excludes: `less/`, `src/`, `views/`, `languages/`, `vendor/`, `node_modules/`, `*.php`.
     (e) Server-side-only reads stay put: `app/system/languages/*.json` is parsed by `IntlModule` in PHP (not fetched over HTTP) — do NOT publish.
  4. **LESS uikit imports move to `node_modules`:** `packages/pagekit/theme-one/less/theme.less` imports `app/assets/uikit/src/less/…` (resolved via the LESS `paths` option) — with the copy relocating to `public/`, import uikit LESS from `node_modules/uikit/src/less/…` instead (add the appropriate `paths` root in `scripts/styles.mjs`; build input must come from the package, not from a served copy). Check all three style roots (installer, system theme, theme-one) for the same pattern. **Empirical gate:** after the build, every non-`data:` `url(...)` in every compiled css under `public/` must resolve to a published file (theme-one sets `@image-path` and compiles without `relativeUrls` — verify, and publish the referenced tree or fix the variable if any refs survive compilation).
  5. **PHP resolution — FileAdapter mounts + locator overlay (the only resolution-layer changes):**
     - `FileAdapter` maps ordered fs-prefix → URL-prefix mounts instead of the single root: primary `path.public → <baseUrl>` (also the base for resolving *relative* localpaths), plus mount `path.storage → <baseUrl> + <storage rel. to approot>` (rel path derived as `substr(path.storage, strlen(path))` — works for the configurable `system/finder.storage`, default `/storage`). Prefix comparisons must be boundary-safe (trailing-slash normalized: `<root>/public/…` matches, `<root>/publicfoo` does not). Files outside all mounts get **no URL — that is the security property, by construction**. Registration stays in `filesystem/index.php`'s `request` listener; `path.storage` exists in every env (root config sets it; finder overrides it before requests).
     - `Locator`: bare-root overlay `add('', <path.public>)` so relative refs (`app/assets/…`) hit the published copy; the module-resource loader in `filesystem/index.php` registers each `resources` prefix with **both** paths, public mirror first, module source second (`add($prefix, [publicMirror, sourcePath])` — mirror = `path.public` + module path relative to approot + resource subpath). PHP views/templates resolve unchanged; bundles/assets resolve to `public/`, `views/*.php` keep resolving to module sources.
     - `filesystem` module reads `path.public` from the container; `index.php` config gains `'path.public' => $path.'/public'` (added to the *root* controller first, carried into `public/index.php` at the flip).
     - **Call-site fixes (verified — only two produce URLs from raw source paths):** editor `index.php` `'root_url' => getStatic(__DIR__)` → locator-based module ref (mind the trailing slash — JS appends `/app/assets/tinymce`); `PackageFactory` `$data['url'] = getStatic($path)` (absolute package source path) → public-mirror-based ref for package icons.
     - **Audit greps (Refactorer runs, fixes stragglers):** `rg -n 'getStatic\(' app/ packages/ --glob '!vendor'`, `rg -n '->getUrl\(|->getPath\(' app/ packages/ --glob '!vendor'` — any caller passing raw absolute source paths or relying on approot-relative localpath resolution.
     - `FinderController` gets `container->get('path')` injected by param name and browses via the client `root` request param with the `system.finder` ACL pinned to `path.storage` — **all physical paths, all unchanged**; its `getStatic($file->getPathname())` URLs work through the storage mount.
  6. **`storage/` split decision: the whole `storage/` tree is the public media library** (that is its role today — finder browses all of it, demo content references it, nothing else writes internal state there). The symlink covers `public/storage → ../storage` entirely. Internal runtime state must never land in `storage/` — enforced forward via the PHASE_2 §2.7 amendment. Defense-in-depth: `public/.htaccess` blocks `.php` execution under `/storage` (`RewriteRule ^storage/.*\.php$ - [F,NC]`) since storage is the only admin-writable served path (finder uploads are already extension-allowlisted). Symlink creation: Node build (`fs.symlinkSync(…, 'junction')` fallback on Windows — junctions need absolute targets) for dev/CI + `Installer` (web + CLI setup) for unzip-on-host installs, warn-don't-fail if `symlink()` is disabled, with the manual command documented in README. If the admin points `system/finder.storage` elsewhere, a matching symlink is required — README documents this; no boot-time self-healing (read-only prod images).
  7. **Front controller:** `public/index.php` = current root `index.php` with `$path = dirname(__DIR__)`, `'path.public' => __DIR__`, cli-server static short-circuit against `__DIR__` (the public dir), debug-log path from `$path`; everything else (env detection, `path.*` map, `require "$path/app/$env/app.php"`) byte-equivalent. Root `index.php` is **deleted** in the same step; `pagekit` bin requires `__DIR__.'/public/index.php'`; `StartCommand` runs `php -S <server> -t public public/index.php` from the app root (CI, `.cursor/start.sh`, Playwright `webServer` all call `php pagekit start` — no workflow edits). Symfony `Request::getBasePath()` handles both hosting modes (docroot=`public/` → basePath `''`; root-fallback rewrite → SCRIPT_NAME `/public/index.php` is not a REQUEST_URI prefix → basePath `''`) — no PHP special-casing.
  8. **`.htaccess` split:** `public/.htaccess` receives verbatim: security headers (incl. the CSP with its documented `unsafe-eval` need — content unchanged), cookie-edit, X-Powered-By unset, www/HTTPS redirects, front-controller rewrite (`!-f`/`!-d` → `index.php`), `SetEnv HTTP_MOD_REWRITE` + header fallback, `RedirectMatch` admin fallback, mime/SVG, deflate, expires — plus the storage php-deny rule (decision 6). **Dropped for good (structurally redundant):** `<FilesMatch>` denials for `.lock|.cache|.db|composer.json|package.json|pnpm-*|CHANGELOG|README|pagekit`, `.htaccess|.ini|.log|.sh|.inc|.bak`-class and backup-file rules — those files no longer exist inside the webroot; keep only `Options -Indexes` and a `.htaccess`-self deny as belt-and-braces. Root `.htaccess` becomes exactly the fallback: `RewriteEngine On` + `RewriteRule ^(.*)$ public/$1 [L,QSA]` (deliberately unconditional — even existing root files like `config.php` are rewritten into `public/` and 404 there; per-dir restart then applies `public/.htaccess`). Dev `Dockerfile` vhost: `DocumentRoot /var/www/html/public` + matching `<Directory>` block.
  9. **Installer/self-updater audit boundaries:** `Installer` ensures the storage symlink (decision 6); `SelfUpdater` gets the minimal consistency patch only — preserve both `.htaccess` files (today it strips the single root one from the zip file list) and do **not** add `public/` to `cleanFolder` (it would wipe gitignored build outputs + the symlink that are absent from update zips); tag with the Step 2.9 TODO. The self-update flow itself remains non-functional (discontinued pagekit.com backend; existing Step 5.6 TODO stays). `path.packages`/`path.artifact`/`config.file` semantics are untouched (all resolve from `$path`, which still points at the app root).
  10. **Inventory parity method:** Step 1 records the ignored-output inventory (`git ls-files --others --ignored --exclude-standard -- '**/app/bundle/*' 'app/assets/*' 'app/system/modules/editor/app/assets/*' 'app/installer/**/css/*' 'app/system/modules/theme/**/css/*' 'packages/pagekit/theme-one/css/*' | sort`) as committed ground truth; the final step's rebuilt inventory under `public/` must equal the baseline with a `public/` prefix, plus the enumerated published-committed-statics additions (each addition traceable to decision 3d) — investigate every other delta.
