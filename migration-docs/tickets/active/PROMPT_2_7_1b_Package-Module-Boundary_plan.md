- **Decisions (Refactorer MUST heed — the plan decides these, not the step):**
  1. **Location and name (AP-04 Escalate, decided here).** `app/package/` beside `app/installer/`, `app/system/`, `app/console/`; module `package`; namespace `Pagekit\Package\`; locator `package:`. Rejected: `app/modules/package` (framework tier — holds no views or admin surface) and `app/system/modules/package` (the tier Step 5.0 makes operator-deactivatable; package management may never be, and `system` requires it). No existing module, service or locator prefix is named `package`; the container service `package` (the factory) and the module `package` live in different registries. The namespace is currently dead: composer.json dropped it in 2.0.5, and `app/modules/application/src/Tests/bootstrap.php` still maps it to a directory that does not exist — that line is deleted in Step 1.
  2. **Class-based main, not a closure (AP-06).** `app/package/src/PackageModule.php`: `final class PackageModule extends Pagekit\Module\Module`, `public function main(App $app): mixed` (same `@return mixed` reason line as `SystemModule::main()`), holding every registration that moves. A closure manifest would read `$this->config` for the retention default and need a new `Undefined variable: $this` baseline entry for `app/package/index.php`; a class reads its own `$this->config` without one. Precedent: `SystemModule`, `IntlModule`. The manifest declares `'main' => 'Pagekit\\Package\\PackageModule'`; `ModuleLoader` instantiates it with the module array and calls `main()`; `ModuleManager::get('package')` then returns that instance (`Module::config()` works for `SnapshotController::retentionDays()`). Tests that boot the old closure via `new Module(['main' => definition()['main']])` boot `new PackageModule([...])->main($app)` instead.
  3. **Namespace mapping flattens the `Package\` segment.** `Pagekit\Installer\Package\X` → `Pagekit\Package\X` (not `Pagekit\Package\Package\X`); sub-namespaces `Lifecycle\`, `Snapshot\`, `Helper\`, `Controller\`, `Extension\` keep their segment. Trap: `PackageManager`, `Package`, `PackageFactory` and both controllers reference same-namespace classes unqualified today — after the move `PackageManager` and the controllers need explicit `use` lines, or PHPStan reports unknown classes. Trap: `tests/Unit/Package/bootstrap.php` defines a namespace-bound `__()` stub for the manager's namespace — it becomes `namespace Pagekit\Package;` in Step 4 or the manager's `__()` calls resolve elsewhere under test.
