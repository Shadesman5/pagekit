- **⚠️ Architect decisions + verified discovery (Refactorer MUST heed):**
  1. **Config chain (verified):** `public/index.php` builds `$config` (paths + `config.file = realpath($path.'/config.php')`) → `app/$env/app.php` adds `ConfigLoader`s in order; **later loaders win** (`array_replace_recursive` per module). Env override = one new loader added **last** in all three boot files (`app/system/app.php` after the root-config block; `app/console/app.php` after its conditional root-config block, before `load()`; `app/installer/app.php` after the installer config loader). `config.php` stays the classic default; env wins in containers. No second configuration framework.
  2. **Env map (fixed, documented; only vars with `getenv() !== false` enter the map — use `getenv()`, NOT `$_ENV`, which is subject to `variables_order`; mod_php inherits the container environment from `apache2-foreground`):**
     - `PAGEKIT_DEBUG` → `application` → `['debug' => (bool)]` (accept `1/true/on` vs `0/false/off`)
     - `PAGEKIT_SECRET` → `system` → `['secret' => string]` (consumed by `SystemModule::$config['secret']`)
     - `PAGEKIT_DB_DRIVER` → `database` → `['default' => 'mysql'|'sqlite']`
     - `PAGEKIT_DB_HOST|PORT|NAME|USER|PASSWORD|PREFIX` → `database.connections.mysql.{host,port(int),dbname,user,password,prefix}`
     - `PAGEKIT_DB_PATH` → `database.connections.sqlite.path` (point at the data volume in containers, e.g. `/var/www/data/pagekit.db` — the module resolves relative paths from the app root and rejects webroot paths)
     - `PAGEKIT_WEATHER_API_KEY` → `system/dashboard` → `['weather.key' => string]` — **flat dotted key**: `Arr::get()` is flat-first, and the module default uses the literal key `'weather.key'`; the override must use the same flat shape.
  3. **Trusted proxies:** `Application::run()` creates the Request (`Request::createFromGlobals()`); configure `Request::setTrustedProxies()` from `PAGEKIT_TRUSTED_PROXIES` (comma-separated IPs/CIDRs, headers `HEADER_X_FORWARDED_FOR|HOST|PORT|PROTO`) right before creation, via a small static helper so it is unit-testable. No-op when unset. Without it, `isSecure()`/generated absolute URLs misreport behind every TLS-terminating proxy.
  4. **`config.php` persistence (container):** `SettingsController` **writes** module config to `config.php` at runtime and `Installer` writes it at install — an immutable image must put it on a volume. Zero-PHP-touch solve: the entrypoint symlinks `/var/www/html/config.php → $PAGEKIT_DATA_DIR/config.php` (default `/var/www/data`, a named volume). Dangling symlink pre-install is correct (`realpath()` false → installer env; `file_put_contents()` through the symlink creates the target). Do NOT add a `PAGEKIT_CONFIG_FILE` PHP override and do NOT relocate config into `storage/` (web-exposed media root).
  5. **Multi-target `Dockerfile` (one file, prod is the LAST stage = default target):**
     - `base`: `php:8.5-apache`, current apt deps + extensions (`pdo_mysql`, `gd`, `zip`; bundled pdo/pdo_sqlite/mbstring/XML implicit), **`a2enmod rewrite headers expires`** — headers/expires are NOT Debian defaults, so today's `IfModule mod_headers` blocks in `public/.htaccess` silently no-op; enabling in `base` gives dev the same effective surface (allowed surgical dev touch: prod build forces it, success criteria require the `.htaccess` behaviour in effect).
     - `dev`: FROM base — today's dev image verbatim (Composer binary, `AllowOverride All` vhost on :80, `EXPOSE 80`, no code baked). Dev compose sets `target: dev`.
     - `composer-deps`: FROM base + Composer binary. Layer caching: `COPY composer.json composer.lock` → `composer install --no-dev --no-scripts --no-autoloader --prefer-dist --no-interaction`; then COPY PHP sources → `composer dump-autoload --no-dev --classmap-authoritative` (classmap needs sources). **Honour `"vendor-dir": "app/vendor"` — never root `vendor/`.**
     - `assets`: `node:22-bookworm-slim` (NOT alpine — shares the glibc family with the Debian runtime, per prompt). `corepack enable` (pnpm pinned via `packageManager`), COPY manifests → `pnpm install --frozen-lockfile`, COPY sources → `pnpm build` (Vite bundles + LESS + asset copies + `public/storage` symlink land in `public/`).
     - `prod`: FROM base. COPY sources (app/, packages/, pagekit bin, public/index.php + public/.htaccess); `COPY --from=composer-deps` `app/vendor`; `COPY --from=assets` `public/`; recreate `public/storage → ../storage` symlink deterministically (`ln -sfn`); prod PHP config (`$PHP_INI_DIR/php.ini-production` as base + `docker/php/php-prod.ini` overlay: `display_errors=Off`, `display_startup_errors=Off`, `expose_php=Off`, `opcache.enable=1`, `opcache.validate_timestamps=0`, `log_errors=On` to stderr, `date.timezone=UTC`, session hardening, sane memory/upload limits); vhost `DocumentRoot /var/www/html/public`, `AllowOverride All` (the committed `public/.htaccess` stays the single source of truth for headers/rewrites — guaranteed parity with the 2.4.1 rule set, shared hosting and container alike), logs → `/proc/self/fd/1` / `/dev/stderr`; **non-root**: `Listen 8080` (unprivileged), Apache run/lock/log dirs writable by `www-data`, create `tmp/{logs,cache,temp,packages,sessions}`, `storage/`, `/var/www/data` owned by `www-data`, then `USER www-data`, `EXPOSE 8080`; `HEALTHCHECK` `curl -fsS -o /dev/null http://127.0.0.1:8080/` (curl fails only ≥400, so the direct-HTTP→HTTPS 301 still reports healthy); OCI labels (`org.opencontainers.image.source=https://github.com/Shadesman5/pagekit` — links the GHCR package to the repo); COPY `docker/entrypoint.sh` to `/usr/local/bin/entrypoint.sh` (executable), `ENTRYPOINT ["entrypoint.sh"]`, `CMD ["apache2-foreground"]` (entrypoint `exec "$@"` for signal handling). **No secrets in any layer; no bind-mount of the tree; migrations/setup never at build time.**
  6. **`.dockerignore` (surgical, one shared file):** stop excluding `docker/` (prod stages COPY `docker/php/php-prod.ini` + `docker/entrypoint.sh`; the dev image copies nothing, so the added context is a few KB); additionally exclude `public/app`, `public/packages`, `public/storage` (host-side build outputs/symlink must not shadow the deterministic in-stage `pnpm build`). Keep `Dockerfile*`/`docker-compose*.yml` excluded (read out-of-band, never COPY'd). No second ignore file, no relocation.
  7. **Entrypoint contract (`docker/entrypoint.sh`):** (a) ensure writable dirs exist (`tmp/*`, `storage/`, `$PAGEKIT_DATA_DIR`) — volumes may mount empty; (b) config symlink per decision 4; (c) if `PAGEKIT_AUTO_SETUP=1` and no `config.php` yet → `php pagekit setup --no-interaction` with flags from `PAGEKIT_DB_*`, `PAGEKIT_ADMIN_USERNAME/PASSWORD/MAIL`, `PAGEKIT_SITE_TITLE`, `PAGEKIT_LOCALE` (verified: `setup` writes `config.php` + schema + admin; re-run against an existing install aborts safely without clobbering; console chain includes the env loader, so setup and runtime see identical env-driven DB config by construction); (d) optional `PAGEKIT_AUTO_MIGRATE=1` → `php pagekit migration:migrate` if its flags allow non-interactive runs (verify; drop the flag if not) — startup, never image build; (e) `exec "$@"`.
  8. **Prod compose (`docker-compose.prod.yml`):** `web` — `image: ghcr.io/shadesman5/pagekit:${PAGEKIT_IMAGE_TAG:-develop}` plus `build: {context: ., target: prod}` fallback, `ports: "8080:8080"`, env wiring (`PAGEKIT_DB_*` ← MySQL vars, `PAGEKIT_SECRET`, optional `PAGEKIT_TRUSTED_PROXIES`/`PAGEKIT_AUTO_SETUP`/admin vars), named volumes `pagekit_data:/var/www/data` + `pagekit_storage:/var/www/html/storage` (named volumes seed ownership from the image; `tmp/` stays container-local), `restart: unless-stopped`, `deploy.resources.limits` (memory + cpus), `depends_on: mysql: condition: service_healthy`; `mysql` — 8.4, named volume, TCP healthcheck mirroring dev, creds from env, **no host port published**; no phpmyadmin/node. SQLite zero-DB path documented (`PAGEKIT_DB_DRIVER=sqlite`, `PAGEKIT_DB_PATH=/var/www/data/pagekit.db`, up `web` only). Env file: `prod.env.example` → copy to `prod.env` (`docker compose -f docker-compose.prod.yml --env-file prod.env up -d`); verify `git check-ignore prod.env` passes. TLS terminates at a fronting proxy that must send `X-Forwarded-Proto: https` (document; pair with `PAGEKIT_TRUSTED_PROXIES`).
  9. **CI workflow (`docker-image.yml`, new job names `hadolint` + `docker-image` — 2.2 required-check names untouched):** triggers = `pull_request` on Docker-relevant paths (Dockerfile, `docker/**`, `docker-compose*.yml`, `.dockerignore`, `prod.env.example`, the workflow itself) → lint + build + smoke + scan, **no push**; `push` to `develop` (unfiltered — code changes must refresh the image) + `workflow_dispatch` → same plus GHCR push.
