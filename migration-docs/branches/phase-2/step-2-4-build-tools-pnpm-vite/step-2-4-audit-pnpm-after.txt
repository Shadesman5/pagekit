# Dependency audit of the pnpm lockfile, recorded after the toolchain swap.
# Counterpart of step-2-4-audit-yarn-before.txt: the two files together show which advisories
# disappear once the webpack, babel, loader, gulp and legacy-ESLint dependency chains are removed.
#
# Command (repository root, node_modules installed with pnpm install --frozen-lockfile):
#
#   pnpm audit
#
# Exit code 1 means advisories were found; that is the expected result, not a failure.
#
# 67 advisories before, 8 after. Every resolved advisory was a transitive dependency of tooling
# that no longer exists - webpack (brace-expansion, braces, micromatch, qs, serialize-javascript),
# babel (@babel/plugin-transform-modules-systemjs), css-loader (postcss), gulp-less (lodash.pick),
# npm-run-all (shell-quote), the replaced ESLint 7 chain (fast-uri, flatted, js-yaml, tmp) and
# vue-template-compiler. picomatch and elliptic never appeared in the before audit, so they cannot
# show up as removed here either.
#
# What remains is runtime, not tooling: seven tinymce advisories (the editor stays pinned at
# ~5.10.9; a TinyMCE 6+ upgrade is its own change) and one low-severity vue ReDoS advisory that
# covers every 2.x release. The before audit was taken with yarn audit --level moderate, which
# does not print low-severity entries - the vue line is newly visible here, not newly introduced.
#
