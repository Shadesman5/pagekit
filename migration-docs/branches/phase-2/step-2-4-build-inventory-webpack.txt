# Baseline inventory of the build outputs produced by the Yarn 1 + Webpack 4 + Gulp pipeline.
# This is the parity ground truth for the pnpm + Vite migration: the inventory regenerated on
# the new pipeline must match this file exactly (same paths, same order).
#
# Regenerate from the repository root after a full build (pnpm install && pnpm build, or on the
# old pipeline yarn install --frozen-lockfile && yarn compile-js --mode=production && yarn gulp):
#
#   git ls-files --others --ignored --exclude-standard -- '**/app/bundle/*' 'app/assets/*' \
#     'app/system/modules/editor/app/assets/*' 'app/installer/assets/css/*' \
#     'app/system/modules/theme/assets/css/*' | LC_ALL=C sort
#
# LC_ALL=C is mandatory. The default en_US.UTF-8 collation orders these paths differently, which
# yields a large diff that contains no actual path-set difference.
#
# Only gitignored (generated) paths are listed, so tracked build outputs are absent by design and
# are checked with git diff instead: packages/pagekit/theme-one/css/theme.css must stay identical
# after regeneration, and the committed editor asset directory
# app/system/modules/editor/app/assets/tinymce_skin/ must survive the asset copies.
#
# Recorded content: 56 JS bundles under **/app/bundle/, 2 compiled stylesheets
# (app/installer/assets/css/installer.css, app/system/modules/theme/assets/css/theme.css) and the
