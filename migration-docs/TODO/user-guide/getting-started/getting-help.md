# Getting Help

<p class="uk-article-lead">There are several channels to reach the developers and the Pagekit community to get direct assistance.</p>

If you can't find the right answers to your questions, you can turn to the following sources to get help and discuss your issues.

## GitHub Issues

If you want to report a bug or contribute your ideas, you can use the [Pagekit GitHub Issues tracker](https://github.com/Shadesman5/pagekit/issues). This is the primary channel for bug reports, feature requests, and contributions.

## Pagekit Blog

Major project news and articles for developers will be published on the Pagekit Blog. This resource is currently in development and will be available soon.

## Documentation

The documentation describes Pagekit on PHP 8.2+ with Symfony 6.4 LTS. Source files for the documentation site are kept under the [Pagekit docs repository](https://github.com/pagekit/docs).
