## ARCHITECT OUTPUT
- **Current Step (ROADMAP):** 2.0.3
- **Scope:** Delete 7 legacy cache files (`CacheInterface`, `Psr6Adapter`, 5 adapter subclasses), rewrite `CacheModule` factory, modernize ORM cache types, migrate 3 consumers to PSR-6, align CLI cache clear, rewrite cache tests.
- **Deferred:** Step 4.3 (Performance) — `TagAwareCacheInterface` for entity-level cache invalidation. Existing TODO in `EntityManager::invalidateCache()` is accurate.

  3. **Modernize ORM cache types** — (a) `app/modules/database/src/ORM/MetadataManager.php`: Remove `use Pagekit\Cache\CacheInterface`, change `$cache` to `?CacheItemPoolInterface`, remove legacy `CacheInterface` branch in `get()`, add `private static function sanitizeCacheKey(string $key): string` that replaces `{}()/\@:` with `_` (preserves `Psr6Adapter::getNamespacedId()` behavior), use it before `getItem()`.
