## Overview

Pagekit platform development is organized in phases:

1. **Foundation** — Symfony 6.4, PHP 8.2+, DBAL 3.x, ORM attributes
2. **Code Quality** — PHPStan, CI/CD, Infection, E2E
3. **Frontend & cross-stack alignment** — Vue 3 migration, translation/Intl ICU, service-layer DI (planned)
4. **Public API** — Versioned REST API with JWT (planned)
5. **Future vision** — Long-term goals beyond the core modernization program

After Phase 4, the roadmap and workflow shift from stack modernization to ongoing
platform evolution and extension ecosystem growth.

The append-only quality metrics history in `MODERNISATION_STRATEGY.md` will remain
as an archive document; the live dashboard is on the [Quality](../quality/index.md) page.
